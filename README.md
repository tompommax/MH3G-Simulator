# MH3G スキルシミュレーター

モンスターハンター3G（MH3G）の装備検索ツール（Windows 用）。
欲しいスキルと条件（職業・性別・レア度上限・武器スロット・所持お守り）から、
防具 5 部位 + お守り + 装飾品の組み合わせを最終防御力の高い順に探します。

> 非公式のファンメイドツールです。株式会社カプコンとは関係ありません。ゲーム内の名称等の権利は各権利者に帰属します。

- 収録データ: 防具 1651 / 装飾品 196 / スキル系統 122
- 生産素材・HR（入手時期）は対象外。進行度の目安は「レア度上限」で絞る

## ダウンロード

[Releases](../../releases) から `MH3GSkillSim.exe` をダウンロードして実行（インストール不要）。

## 動作環境

- 64bit 版 Windows 10 / 11。.NET ランタイムは exe に同梱済みなので、.NET のインストールは不要
- ダウンロードした exe で「Windows によって PC が保護されました」と出た場合は、exe を右クリック →「プロパティ」→「許可する」にチェック → OK（新しい版をダウンロードした時はもう一度）

## 使い方

1. 基本条件で職業・性別・レア度上限・武器スロットを選ぶ
2. 欲しいスキルを左のリストからダブルクリック（または絞り込み欄に入力して Enter）で追加。右のリストをダブルクリックで削除
3. 所持お守りを登録: スキル1 → ポイント → スロット → スキル2 → ポイントの順にプルダウンで選んで「追加」。スキルはお守りに付き得るもの、ポイントはそのスキルの最大値まで（第 2 スキルは -10 まで）、スロットは 0〜3 が選択肢に出る。一覧で選んで「選択を削除」（Delete キーも可）。`%APPDATA%\MH3GSkillSim\charms.json` に自動保存。**装備できるお守りは 1 つだけ**で、検索では登録したお守りを 1 つずつ試して（「お守りなしも候補にする」ならお守りなしも）一番良い組み合わせを選ぶ
4. 「検索」。結果を選ぶと下に防具・装飾品の配置・発動スキル・耐性・スキルポイント合計を表示
5. 結果を右クリック →「この○防具を除外して再検索」で候補から外せる（「除外を解除」で戻す）
6. テキスト出力: 「テキスト保存」で全件をファイルに保存（先頭に検索条件付き）。結果を右クリック →「この結果をコピー」「この結果をテキスト保存」で 1 件だけ

「マイナススキルを発動させない」を外すと、マイナススキルが付く構成も候補に入る。
要求スキルのポイントとスロットが同じ防具は 1 件にまとめ、詳細欄に「同等品」として並べる（差し替え時のマイナススキルは各自確認）。
ステータス欄に「珠の探索を打ち切り」と出た時は、非常に多くの珠が必要な構成を見落としている可能性がある。

## データの修正

装備・装飾品・スキル・お守りのデータは `src/Mh3gSim.Core/Data/` の JSON で、ビルド時に exe に埋め込まれる。**1 行 = 1 件**なので、名前で検索してその行だけ直せばよい。

| ファイル | 1 行の内容 |
|---|---|
| `armors.json` | 1 防具: `id`（除外機能の識別用。重複不可）, `part`（頭 / 胴 / 腕 / 腰 / 脚）, `name`, `class`（両方 / 剣士 / ガンナー）, `sex`（両方 / 男 / 女）, `rarity`, `defense`（初期）, `maxDefense`（最終）, `slots`（0〜3）, `skills`（{"系統": ポイント}、胴系統倍化は `"胴系統倍化": 1`）, `resist`（{"火", "水", "氷", "雷", "龍"}） |
| `decorations.json` | 1 装飾品: `name`, `slots`（1〜3）, `skills`（プラスの系統 1 つ + マイナスの系統） |
| `skills.json` | 系統ごとのまとまりで、1 行 = 1 発動スキル: `points`（必要ポイント。マイナススキルは負）, `name`, `description` |
| `charms.json` | `categories`: お守りの系統ごとのスロット上限・第 2 スキルの有無と下限（`types` は鑑定後の護石名の参考情報）。`maxPoints`: 1 行 = 1 スキルで、系統ごとの最大ポイント（書いていない系統にはそのスキルは付かない）。入力欄では系統を区別せず、どれかの系統で付き得るスキルと一番大きい最大値・スロット上限を使う |

直したら、次で確認してから exe を作る（`publish.ps1` も最初に同じチェックを行い、問題があれば exe を作らない）。

```powershell
dotnet run --project tools/Mh3gSim.Bench -c Release -- --check-data
```

JSON の書き方を間違えた時（カンマの過不足など）や、知らないスキル名・部位名がある時は、ファイル名と行・防具名つきで表示される。お守りの表は元情報が暫定値なので、実物と違っていたら `maxPoints` の該当行を直す。

## ビルド

.NET 9 SDK が必要。

```powershell
./scripts/publish.ps1   # publish/MH3GSkillSim.exe を出力
```

検索ロジックの確認用ベンチ: `dotnet run --project tools/Mh3gSim.Bench -c Release -- 攻撃:20 達人:10 --weapon 1`
（`--brute` で総当たりと最上位を突き合わせる。レア度上限を小さくして使う）。検索アルゴリズムは [docs/DESIGN.md](docs/DESIGN.md)。
