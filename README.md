# MH3G スキルシミュレーター

モンスターハンター3G（MH3G）の装備の組み合わせを探す、Windows 用のツールです。
欲しいスキルと条件（職業・性別・レア度上限・武器スロット・お守り）を指定すると、
防具 5 部位・お守り・装飾品の組み合わせを、最終防御力の高い順に表示します。

> 非公式のファンメイドツールです。株式会社カプコンとは関係ありません。ゲーム内の名称等の権利は各権利者に帰属します。

- 収録データ: 防具 1651 件、装飾品 196 件、スキル系統 122 件
- 生産に必要な素材と HR（入手できる時期）には対応していません。進行度に合わせたい時は「レア度上限」で絞り込んでください。

## ダウンロード

[Releases](../../releases) から `MH3GSkillSim.exe` をダウンロードして、そのまま実行してください。インストールは不要です。

## 動作環境

- 64bit 版の Windows 10 / 11 で動きます。.NET ランタイムは exe に含まれているので、.NET を別にインストールする必要はありません。
- ダウンロードした exe を開いた時に「Windows によって PC が保護されました」と表示された場合は、exe を右クリック →「プロパティ」→「許可する」にチェックを入れて「OK」を押してから、もう一度開いてください。新しい版をダウンロードした時も同じ操作が必要です。

## 使い方

1. 「基本条件」で職業・性別・レア度上限・武器スロットを選びます。
2. 欲しいスキルを追加します。左のリストでスキルをダブルクリックするか、「スキル名で絞り込み」の欄に入力して Enter を押してください。追加したスキルは、右のリストでダブルクリックすると外せます。
3. 装備するお守りを入力します（**お守りは 1 つだけ装備できます**）。スキル1 → ポイント → スロット → スキル2 → ポイントの順に、プルダウンから選んでください。
   - 選択肢に出るのは、お守りに付く可能性があるスキルと、そのスキルの最大値までのポイント（第 2 スキルは -10 まで）、0〜3 のスロットです。
   - お守りを使わない時は、スキル1 を「（なし）」にします。
   - 入力したお守りは `%APPDATA%\MH3GSkillSim\charms.json` に自動で保存され、次に起動した時も残ります。
4. 「検索」を押します。結果の行を選ぶと、画面の下に防具・装飾品の付け方・発動スキル・耐性・スキルポイントの合計が表示されます。
5. 候補から外したい防具がある時は、結果を右クリックして「この頭防具を除外して再検索」などを選びます（部位ごとにあります）。「除外を解除」ボタンで元に戻せます。
6. 結果をテキストで保存できます。
   - 「テキスト保存」ボタン: 全件をファイルに保存します（先頭に検索条件が入ります）。
   - 結果を右クリック →「この結果をコピー」または「この結果をテキスト保存」: 1 件だけコピー・保存します。

補足:

- 「マイナススキルを発動させない」のチェックを外すと、マイナススキルが発動する組み合わせも表示します。
- 要求スキルのポイントとスロット数が同じ防具は 1 件にまとめ、詳細欄に「同等品」として並べます。同等品に差し替える時は、マイナススキルが出ないかをご自身で確認してください。
- ステータス欄に「珠の探索を … 構成で打ち切り」と表示された時は、装飾品を非常に多く使う組み合わせを見落としている可能性があります。

## データの修正

装備・装飾品・スキル・お守りのデータは、[src/Mh3gSim.Core/Data](src/Mh3gSim.Core/Data) フォルダにある次の 4 つの JSON ファイルです。どのファイルも 1 行に 1 件ずつ書いてあるので、直したい防具やスキルの名前で検索して、その行だけを書き換えてください。

| ファイル | 1 行に書いてある内容 |
|---|---|
| [armors.json](src/Mh3gSim.Core/Data/armors.json) | 防具 1 件。`id`（除外機能で使う番号。ほかの防具と重ならないようにします）、`part`（頭 / 胴 / 腕 / 腰 / 脚）、`name`（名前）、`class`（両方 / 剣士 / ガンナー）、`sex`（両方 / 男 / 女）、`rarity`（レア度）、`defense`（初期防御力）、`maxDefense`（最終防御力）、`slots`（スロット数 0〜3）、`skills`（`{"系統名": ポイント}`。胴系統倍化は `"胴系統倍化": 1`）、`resist`（火・水・氷・雷・龍の耐性） |
| [decorations.json](src/Mh3gSim.Core/Data/decorations.json) | 装飾品 1 件。`name`（名前）、`slots`（使うスロット数 1〜3）、`skills`（プラスの系統 1 つと、マイナスの系統） |
| [skills.json](src/Mh3gSim.Core/Data/skills.json) | 発動スキル 1 件（同じ系統のスキルがまとめて並んでいます）。`points`（発動に必要なポイント。マイナススキルは負の値）、`name`（スキル名）、`description`（説明） |
| [charms.json](src/Mh3gSim.Core/Data/charms.json) | お守りの表。`categories` は、なぞのお守り・光るお守り・古びたお守り・風化したお守りのそれぞれについて、スロットの上限と、第 2 スキルが付くかどうか・その下限を書いたものです（`types` は鑑定後の護石の名前で、参考情報です）。`maxPoints` は 1 行 = 1 スキルで、4 つのお守りそれぞれで付く最大ポイントです（書いていないお守りには、そのスキルは付きません）。入力欄ではこの 4 つを区別せず、どれかで付くスキルを選択肢に出し、ポイントとスロットは一番大きい上限を使います |

このデータはビルドの時に exe の中に組み込まれます。そのため、Releases で配布している exe の横にはデータのファイルがありません。データを直したら、下の「ビルド」の手順で exe を作り直してください。

exe を作る前に、次のコマンドでデータに誤りがないかを確認できます。`publish.ps1` も最初に同じ確認を行い、問題があれば exe を作りません。

```powershell
dotnet run --project tools/Mh3gSim.Bench -c Release -- --check-data
```

JSON の書き方の誤り（カンマの過不足など）や、存在しないスキル名・部位名があると、ファイル名と行番号（防具なら防具名も）を表示します。お守りの表は暫定値です。実際のお守りと違っていたら、`charms.json` の `maxPoints` の該当する行を直してください。

## ビルド

.NET 9 SDK が必要です。リポジトリの一番上のフォルダで次のコマンドを実行すると、`publish/MH3GSkillSim.exe` ができます。

```powershell
./scripts/publish.ps1
```

検索ロジックを確かめるためのベンチもあります。

```powershell
dotnet run --project tools/Mh3gSim.Bench -c Release -- 攻撃:20 達人:10 --weapon 1
```

`--brute` を付けると、総当たりで求めた 1 位と検索結果の 1 位を突き合わせます。総当たりは時間がかかるので、`--rare 3` などでレア度上限を小さくして使ってください。検索アルゴリズムの説明は [docs/DESIGN.md](docs/DESIGN.md) にあります。
