# MH3G スキルシミュレーター

モンスターハンター3G（MH3G）の装備検索ツール（Windows 用）。
欲しいスキルと条件（職業・性別・レア度上限・武器スロット・所持お守り）から、
防具 5 部位 + お守り + 装飾品の組み合わせを最終防御力の高い順に探します。

> 非公式のファンメイドツールです。株式会社カプコンとは関係ありません。ゲーム内の名称等の権利は各権利者に帰属します。

- 収録データ: 防具 1651 / 装飾品 196 / スキル系統 122
- 生産素材・HR（入手時期）は対象外。進行度の目安は「レア度上限」で絞る

## ダウンロード

[Releases](../../releases) から `MH3GSkillSim.exe` をダウンロードして実行（インストール不要）。

## 動作環境

- 64bit 版 Windows 10 / 11。.NET ランタイムは exe に同梱済みなので、.NET のインストールは不要
- ダウンロードした exe で「Windows によって PC が保護されました」と出た場合は、exe を右クリック →「プロパティ」→「許可する」にチェック → OK（新しい版をダウンロードした時はもう一度）

## 使い方

1. 基本条件で職業・性別・レア度上限・武器スロットを選ぶ
2. 欲しいスキルを左のリストからダブルクリック（または絞り込み欄に入力して Enter）で追加。右のリストをダブルクリックで削除
3. 所持お守りを表に入力（スキル名は入力補完あり。`%APPDATA%\MH3GSkillSim\charms.json` に自動保存）
4. 「検索」。結果を選ぶと下に防具・装飾品の配置・発動スキル・耐性・スキルポイント合計を表示
5. 結果を右クリック →「この○防具を除外して再検索」で候補から外せる（「除外を解除」で戻す）

「マイナススキルを発動させない」を外すと、マイナススキルが付く構成も候補に入る。
要求スキルのポイントとスロットが同じ防具は 1 件にまとめ、詳細欄に「同等品」として並べる（差し替え時のマイナススキルは各自確認）。
ステータス欄に「珠の探索を打ち切り」と出た時は、非常に多くの珠が必要な構成を見落としている可能性がある。

## ビルド

.NET 9 SDK が必要。

```powershell
./scripts/publish.ps1   # publish/MH3GSkillSim.exe を出力
```

検索ロジックの確認用ベンチ: `dotnet run --project tools/Mh3gSim.Bench -c Release -- 攻撃:20 達人:10 --weapon 1`
（`--brute` で総当たりと最上位を突き合わせる。レア度上限を小さくして使う）。検索アルゴリズムは [docs/DESIGN.md](docs/DESIGN.md)。
